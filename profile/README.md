# AI DevOps Learning

Hands-on projects for learning DevOps, GitHub Actions, containers, and
AI-assisted engineering, built in the open.

## Start here

- **Browse the repositories** to find a project that interests you.
- **Reuse our CI/CD:** in any repository in this organization, go to
  *Actions → New workflow* and pick one of the
  [shared workflow templates](https://github.com/ai-devops-learning/.github/tree/main/workflow-templates).
- **Contribute:** read the
  [contributing guide](https://github.com/ai-devops-learning/.github/blob/main/CONTRIBUTING.md).
