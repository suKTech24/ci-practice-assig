# Support

## How to get help

| You want to... | Go here |
| --- | --- |
| Ask a usage question | The repository's **Discussions** tab, if enabled. Otherwise, the organization's [discussions](https://github.com/orgs/ai-devops-learning/discussions) |
| Report a bug | A new issue using the *Bug report* form |
| Request a feature | A new issue using the *Feature request* form |
| Report a security vulnerability | [SECURITY.md](SECURITY.md). **Not** a public issue |
| Report a Code of Conduct violation | [Private reports](#private-reports) |

Before you post, search existing issues and discussions. Your question may
already have an answer.

## Private reports

For conduct concerns or anything else that shouldn't be public, contact the
organization owners listed in [GOVERNANCE.md](GOVERNANCE.md) directly on
GitHub. You can also use GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature.

## Support expectations

Projects in this organization are maintained on a best-effort basis. There is
no guaranteed response time or commercial support. Clear, reproducible reports
get help the fastest.
